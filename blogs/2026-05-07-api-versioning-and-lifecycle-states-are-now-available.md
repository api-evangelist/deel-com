Hey everyone, We’re excited to share that we’ve shipped API versioning and lifecycle states—giving developers more control and confidence when building on the Deel API. Until now, shipping new functionality meant asking every integration to migrate at the same time, so instead of improving endpoints, we’d create new variants and widen the integration surface. With API versioning and lifecycle states, you can now: Move at your own pace.
